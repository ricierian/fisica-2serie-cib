# Física 2ª série · CIB

Listas interativas de Física da 2ª série do Colégio Israelita Brasileiro (Prof. Ricieri), com dica e resolução passo a passo. App instalável (PWA) publicado pelo GitHub Pages.

- `fonte/`: arquivos-fonte (`lista1.js` … `lista6.js`, `engine_app.js` com `SITE` e `CONFIG`). Para montar o `index.html`: `python3 fonte/montar.py`.
- `registro/Codigo.gs`: script da planilha de registros (Google Apps Script).
- A cada publicação, aumentar `VERSAO` em `sw.js`.
